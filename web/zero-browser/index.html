Privacy contract

Browsing is not a telemetry product.

Community 0.3 has no analytics endpoint, advertising identifier, account requirement or remote-control channel. Its privacy promise is specific and testable—not a vague “private mode” badge.

Community 0.3 does not collect

  • Browsing history or visited page content.
  • Form entries, cookies or search queries.
  • Private-browsing history or diagnostics.
  • Affiliate-attribution replacements.
  • Automatic page screenshots or memory contents.

Network expansion requires disclosure

  • Update checks disclose only documented release fields.
  • Diagnostics remain a separate opt-in.
  • URLs, query strings and user identifiers are scrubbed.
  • Sync must be independently encrypted before release.
  • Any policy change requires clear release notes.

Browser security architecture

A browser fork is an update operation, not a paint job.

A separately maintained ZSEC Browser binary would have to preserve Chromium’s process separation, renderer sandbox and Site Isolation while keeping its patch set deliberately small. Community 0.3 is the extension protection layer and does not claim to be that binary.

  • Never ship with the Chromium sandbox disabled.
  • Never install a root certificate to inspect traffic.
  • Merge upstream security fixes weekly and on emergency cadence.
  • Use signed update metadata with expiry and rollback protection.
  • Carry complete Chromium and third-party licence notices.

Questions, answered plainly

ZSEC Browser FAQ

Is ZSEC Browser already a standalone browser?

ZSEC Browser Community 0.3 is an auditable Manifest V3 protection layer delivered as ZSEC Browser Shields. It installs manually in Chromium-family browsers; a separately maintained Chromium binary is not included.

Does ZSEC Browser block every YouTube ad?

It applies local declarative blocking rules and best-effort interface cleanup. YouTube and other sites change frequently, so no honest blocker can promise uninterrupted coverage on every site.

Does ZSEC Browser collect browsing history?

Community 0.3 does not collect or upload browser history, page content, form data, cookies or search queries. It has no analytics, account or crash-upload endpoint.

Does ZSEC Browser install a root certificate or inspect encrypted traffic?

No. The extension does not proxy traffic, install a local root certificate or break TLS. It works inside Chromium's extension boundary and does not weaken the browser sandbox or Site Isolation.

How do I verify the ZSEC Browser Shields package?

Download the versioned ZIP and checksum, calculate SHA-256 locally, compare the exact value, inspect the open source and load the unpacked package only in a dedicated Chromium profile.

How would a ZSEC Browser distribution stay secure as Chromium changes?

Any browser distribution needs a deliberately small patch set, automated upstream monitoring, weekly and emergency security merges, signed update metadata, staged release rings and tested rollback. That operation has not shipped, so the project is not described as a maintained Chromium browser binary.
