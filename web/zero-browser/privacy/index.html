ZeroQ Shields extension preview

Privacy should be a testable contract.

ZeroQ Shields evaluates its packaged blocking rules and site-pause choices locally. The current preview has no analytics, advertising, account, crash-upload, cloud-reputation or remote-control endpoint.

Effective and last reviewed: 21 August 2026. This policy applies to the public Manifest V3 extension preview in the ZSEC Shield repository.

Processed locally

What the extension uses

  • Packaged declarative ad and tracker rules.
  • The global protection on/off setting.
  • Domain names the user explicitly pauses.
  • Page-interface signals used for best-effort YouTube cleanup.

These operations happen inside the browser. The current extension sends no report about them to TalkToAI.

Not collected or transmitted

What we do not receive

  • Browsing history, full URLs, searches or page text.
  • Cookies, form fields, credentials or payment details.
  • Files, downloads or clipboard contents.
  • Advertising identifiers, analytics events or crash reports.
  • Affiliate-attribution replacements or shopping-link rewrites.

Permissions

Why broad site access exists

A network blocker must be able to evaluate requests across websites, and the interface-cleanup script must run on the sites it supports. That access is not permission to build a browsing profile or transmit page contents. The extension uses Manifest V3 packaged code and rules; it does not download or execute remote code.

Paused domains and the protection toggle remain in the browser extension's local storage. Removing the extension removes its locally stored settings through the browser's normal extension lifecycle. Zero Browser has no server-side account record to delete for this preview.

Future changes

No silent expansion.

Any future cloud reputation, diagnostics, sync or sample submission must be a separately disclosed feature with a specific purpose, destination, retention period and user control. It may not silently weaken this contract. Material policy changes require a new review date and release notes.

Security issues can be reported through the repository's security policy.
