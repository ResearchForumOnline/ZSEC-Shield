Four-minute setup

Load the folder. Keep the warning visible.

Developer mode is intentionally explicit. Use a test profile first, review the requested permissions, and keep your browser current.

Download and verify

Save the ZIP, compare its SHA-256 with the published value, then extract it to a folder you will not move.

Open extensions

Visit chrome://extensions, edge://extensions or brave://extensions in the matching browser.

Enable developer mode

Turn on Developer mode, choose Load unpacked, and select the extracted folder containing manifest.json.

Pin and test

Pin ZeroQ Shields, open its panel, confirm rules are on, then test normal sites before relying on the profile.

!

Do not ignore browser warnings

Chrome-family browsers remind you about developer-mode extensions because unpacked packages are outside normal Store review and automatic updating. That warning is accurate. Remove the preview from chrome://extensions if you no longer want to test it.

Working protection

Useful now. Narrow enough to audit.

The preview aims to beat opaque privacy tools on inspectability and control. It does not claim Brave-level browser maintenance, anonymity or complete malicious-site protection.
