# Zero Security brand system

## Product names

- **Zero Security** is the cross-platform desktop security product family.
- **ZSEC Shield** remains the current scanner/core lineage.
- **Zero Security for Windows** is the future primary-antivirus programme.
- **Zero Security for macOS** and **Zero Security for Linux** are separately
  gated desktop programmes, not capabilities claimed by the current CLI.
- **Zero Browser** is the browser product.
- **ZeroQ Shields** is the reusable blocking and privacy engine.
- **Zero Qbrowser** is a working codename, not the public canonical name.

Canonical public routes are `https://talktoai.org/zero-security/` and
`https://talktoai.org/zero-browser/`. Naming still requires normal trademark and
store-listing clearance before a paid release.

## Visual language

- Near-black foundations: `#07100f` and `#0b1715`.
- Protection green: `#18e0a7`.
- Boundary cyan: `#55ffd0`.
- Evidence blue: `#238cff`.
- Quiet text: `#9cb7b0`.
- Directional arcs and a zero-shaped protected core communicate the ZBA
  entering, boundary, and emerging lifecycle without implying that the symbol
  itself supplies cryptographic strength.

The SVG mark is the deterministic source for UI icons and monochrome variants.
The generated raster artwork is for launch surfaces and should not be redrawn
by tracing third-party browser or antivirus branding.

## Public voice

Calm, precise, and evidence-led. Prefer “processed locally,” “authenticated
encrypted vault,” “bounded local filtering,” and “Community security companion.”
The product name may use “ZSEC Antivirus,” but primary-provider or native
real-time claims require the exact platform evidence gates. When Microsoft
Defender supplies enforcement, name Defender explicitly and describe ZSEC as
the control plane and companion. Avoid “unhackable,” “military grade,” “quantum encryption,”
“blocks everything,” or unsupported comparison claims.
