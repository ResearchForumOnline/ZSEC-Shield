# ZSEC Antivirus 0.3.37 Windows desktop

This corrective release addresses routine folder notifications that persisted in
0.3.36. Folder-access, exclusion, startup-inventory and observer recovery details
never cause desktop popups. Actual configured-rule detections, integrity failures
and primary Windows protection faults retain bounded security notifications.

Standard user folders are selected automatically. A responding observer has calm
running status even during commissioning or partial file inspection; Advanced
options retain explicit incomplete coverage evidence. A successful whole-root
reconciliation can restore recoverable current inspection/inventory state, while
historical errors remain in session reports and audit events. A successful
unrelated file scan cannot erase a coverage failure. Queue loss, root/backend,
trust and quarantine failures remain fail-closed.

Microsoft Defender or another supported primary antivirus provides real-time
pre-access protection. ZSEC remains an additional post-change security companion,
with signed advisory maintenance, local evidence, supported Windows health checks
and optional encrypted recovery. This release adds no independent malware-efficacy
claim or Windows Security provider registration. Store manages executable updates.
The enabled package-owned startup task respects Windows user and administrator
choices. Existing remembered pauses remain respected.

## Validation and interpretation

Regression coverage includes incomplete initial inventory, transient inspection
failure recovery, unrelated clean scans, retained access/size gaps, historical
error retention, persisted health, malformed recovery fields, silent routine
folder notifications and retained detection/integrity/Windows alerts. An isolated
Tk layout uses a mock bridge and is a development check, not installed protection
or Store acceptance evidence.

A local native 0.3.36 observation against the real three standard roots processed
229,187 metadata files before a bounded 90-second harness timeout: 44 fresh
heartbeats, 62 successful scan batches, 51 files hashed and no observed health or
scan issues. Initial inventory had not finished. This independently demonstrates
that an incomplete inventory can coexist with active monitoring; the screenshot
alone does not prove a failed engine. Local raw path logs remain private and are
excluded from release assets.

Exact release tests, package hashes, CI and Partner Center disposition are recorded
in the delivery receipt after verification. Submission is distinct from Microsoft
certification, public availability and an installed client upgrade.
